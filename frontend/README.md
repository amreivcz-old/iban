# React + TypeScript + Vite

Run commands from `frontend/` using Node.js 24 LTS or newer:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Edit `src/App.tsx` to start building the UI.

```sh
npm run build
npm run lint
npm run preview
```

The build command checks TypeScript and generates the production bundle in `dist/`.
The Spring Boot backend runs separately from `../backend/`.
